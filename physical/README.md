# Physical-design scope

RTL-to-GDS is a V2 stretch goal in the canonical specification. V1 includes reproducible generic synthesis and Nangate45 mapped pre-layout STA. No floorplan, placement, CTS, routing, extracted parasitics, DRC, or GDS result is claimed. The timing scripts and pinned library fetch are structured as inputs to a future OpenROAD-flow-scripts design configuration.
